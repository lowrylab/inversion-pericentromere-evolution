# Mechanistic within-orientation variation arm

This arm preserves the completed perfectly coupled maintenance baseline as the reference and uses the exact same validated recombination rule. It introduces neutral two-marker phase variation within A and B so A/A and B/B recombination can create observable 10/01 recombinant phases.

Production design: `m=0,0.01,0.05`, 50 replicates per model per migration, N=1000, GENS=10000, matched seeds, 300 runs total. Each SLURM task requests one CPU core.

Run `slurm/check_hpcc_environment.sbatch` first to identify the current MSU module name and SLiM 5.1 executable. Submit the smoke and production jobs with `SLIM_MODULE=<module-name>` after that check; the job scripts load the supplied module inside the job and otherwise use `SLIM_BIN` from PATH.

Before HPCC production, run the local smoke test in `validation/mechanistic_smoke` and the small HPCC test described in the design report. The array is submitted with `slurm/submit_mechanistic_array.sbatch`; task definitions are generated by `manifest/make_manifest.py`; completion status is checked by `slurm/check_completion.py`.

The model is `models/mechanistic_within_orientation_variation.slim`. Its expected SHA256 is recorded in the design report and should be checked again after copying the project to HPCC.

## Final local smoke gate

The exact production model was run at N=1000, GENS=1000, LOG_EVERY=1000, m=0.01, seed=20260928, for both treatments. Initial phase records were exactly 0.50/0.50 parental 11/00 within every A and B class, with 0/0 recombinant phases. Adaptive initialization was m2=m3=m5=m6=1.0 on their intended orientation classes. At generation 1000, inversion had nonzero within-A and within-B recombinant phases (p1 A 10=.652, B 10=.0405; p2 A 10=.480, B 10=.0 in this stochastic smoke run), while permanent suppression had zero recombinant phases in all classes. The inversion callback remains the unchanged A/A-allowed, A/B-suppressed, B/B-allowed rule; the permanent callback suppresses all internal recombination. m2/m3 and m5/m6 retain the source-defined antagonistic fitness effects. LOAD totals agree with mean × class count and population contributions agree with total/(2N) to printed precision.

Smoke outputs are in `../validation/mechanistic_smoke/`. The HPCC smoke array is prepared but has not been submitted from this environment because no `sbatch` client or MSU HPCC connection is available here. Full production submission is intentionally gated on that HPCC smoke comparison.
