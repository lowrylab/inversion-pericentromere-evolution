# Methods summary

The maintenance baseline contains 7 migration values (0, 0.001, 0.005,
0.01, 0.02, 0.03, 0.05), 50 matched replicates per treatment and migration,
and 700 total runs. Arm B contains 3 migration values (0, 0.01, 0.05), 50
replicates per treatment and migration, and 300 planned runs.

Primary outcomes are orientation frequency, adaptive-locus frequency and LD,
loss/fixation frequencies, A/A–A/B/B/B occupancy, conditional burden among
surviving orientation haplotypes, total orientation-associated burden,
population-wide focal burden, and burden distributions.

Interpretation is replicate-level. Means alone are insufficient because the
constitutive treatment can be bimodal. Ten-thousand-generation outputs are
treated as endpoints, not equilibria.
