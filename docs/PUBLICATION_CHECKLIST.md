# Publication-readiness checklist

- [ ] Every biological claim links to a result table, figure, or analysis.
- [ ] Conditional and constitutive recombination rules are stated explicitly.
- [ ] Current model hashes and any new model versions are recorded.
- [ ] Code provenance and archived third-party material are reviewed.
- [ ] Licenses and required notices are verified.
- [ ] `CITATION.cff` and `docs/CITATION_GUIDE.md` are current.
- [ ] Code, computational, and scientific-robustness reproducibility are
      assessed separately.
- [ ] All production task manifests are complete and checksummed.
- [ ] Figures and tables regenerate from documented inputs.
- [ ] External raw data or archives are identified if needed.
- [ ] AI-assisted development disclosure is reviewed.
- [ ] Human collaborators and contributors are acknowledged appropriately.
- [ ] Arm B is labeled according to actual execution status.
- [ ] A versioned release is created only after scientific and attribution
      review.
