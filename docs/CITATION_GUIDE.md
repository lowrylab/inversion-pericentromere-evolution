# Citation and reuse guide

## Cite this repository

For a development checkout, cite the repository URL and the version shown in
`CITATION.cff`. Once a Zenodo or institutional release exists, cite that
versioned release and add its DOI to `CITATION.cff`; no DOI is claimed here.

## Cite inherited work

Users of the current models should also cite the relevant original scientific
and computational sources in `docs/REFERENCES.md`, especially Berdan et al.
(2021), StevisonLab/Slim_ICE where relevant to reused context, and the SLiM 5
and Eidos software references.

The public Slim_ICE repository and the local legacy snapshot were compared for
model family and algorithmic ancestry. The current two-population models were
not presented as direct copies of the public repository. Exact file-level
identity could not be established for every historical file because the local
snapshot and public repository do not provide a common provenance manifest.

## Citation versus license

Citation and acknowledgment are scholarly requests. They are distinct from
the legal permissions and obligations of the MIT license. Historical archived
ICE files have an additional license-verification notice under
`archive/legacy_ice/NOTICE.md`.
