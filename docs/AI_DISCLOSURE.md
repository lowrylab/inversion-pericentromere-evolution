# AI-assisted research disclosure

David B. Lowry directed the scientific questions, biological assumptions,
experimental design, interpretation, and final decisions.

ChatGPT assisted with experimental planning, scientific reasoning, literature
review, and review of analyses. Codex assisted with model implementation,
validation tests, computational execution, repository construction, and
reproducibility auditing.

AI systems are tools and are not authors. All scientific claims, code choices,
citations, and release decisions require human review by the project authors.
