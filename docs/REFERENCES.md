The current project uses references 1–9 for simulation framework, inversion,
local-adaptation, load, and biological context. References 10–15 document
parameter sources or historical context named by the archived ICE branch;
they are not automatically sources for the current two-population parameter
values. This project does not claim to implement canonical Slim_ICE or the
conventional inversion recipe: its A/B rule is an intentional
genotype-dependent suppression model.
