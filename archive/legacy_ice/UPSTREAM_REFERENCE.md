# Upstream ICE reference

Public repository: <https://github.com/StevisonLab/Slim_ICE>

The public README describes the project as forward-time SLiM simulations of
chromosomal inversions with interchromosomal effects, directly extending the
Berdan et al. (2021) framework. It credits Laurie Stevison as the author of
the SLiM models and computational work, with Spencer Koury collaboration.

The source files are not redistributed in this repository because the GitHub
repository has no machine-readable license declaration and its README and
Zenodo metadata report conflicting terms. Consult the upstream repository and
Zenodo record before obtaining or reusing those files.
