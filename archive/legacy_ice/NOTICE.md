# Legacy ICE archive notice

The initial public release intentionally does not redistribute the legacy ICE
source files. The original private working directory retains them, and
`FILE_HASH_COMPARISON.tsv` records their byte-level relationship to the public
repository at commit `73fdcba3fcb673ee85f70cec51aff770d308c382`.

The public GitHub repository currently has no machine-readable LICENSE file.
Its README states MIT licensing, while the associated Zenodo release metadata
for DOI `10.5281/zenodo.20170793` reports `CC-BY-4.0`. Until the upstream
authors clarify which terms govern the source files, redistribution is
intentionally withheld.

The current project cites and links to the upstream work for provenance. It
does not present the legacy ICE code as current production code.
